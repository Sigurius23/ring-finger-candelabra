# Versions

Each zip holds the print files (STL), reports and README of one design version.
The scripts that made each version are in the git history (`git log`).

| Version | What changed |
|---|---|
| v1 | First wax and bone fingers (stylised, plain tubes). Not kept here: it is the first zip sent in the chat. |
| v2 | Wax fingers with pads, nail and creases (still tube-like). Not kept here: it was overwritten. |
| v3 | `v3-human-male-drips-poseable-bones.zip`: continuous human (male) fingers, wax drips, first poseable bone kit with visible pins. |
| v4 | `v4a-female-fingers.zip` and `v4b-male-fingers-and-bones.zip` (split to stay under GitHub's 100 MB file limit): slender female fingers (detailed, drips, smooth), bone kit with hidden joints, slimmer bones. |
| v5 | `v5-curling-fingers.zip`: female fingers that curl, jointed in the knuckle creases. |
